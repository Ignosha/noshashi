## AlternativeTo / SaaSHub

- Name: NOSHASHI
- Site: https://www.noshashi.app
- Platforms: macOS, Windows, Linux, Web
- License: package.json says MIT, but the repo has no LICENSE file yet. Add one before listing the license, or leave the field blank.
- Short description:

```
Read-only compliance and risk layer for the XRP Ledger. It checks what an
issuer can still do to holders (freeze, permission to hold, signing
keys), separates fillable from advertised order-book depth, reads
delivered amounts on partial payments, and screens for OFAC-listed
senders up to three hops back. Every decision gets a SHA-256 receipt
against a versioned policy. It never asks for keys.
```

- Tags: xrpl, xrp, compliance, aml, blockchain-analytics
