# Public launch kit

Drafts for getting NOSHASHI known, written to be posted by Joshua Edmond
from his own accounts. Nothing here has been posted. Every channel is free.

Every post follows the same rules as outreach:
- Every figure is quoted with its ledger index and the date it was read.
  Re-run the reading on the day you post and replace the numbers; ledger
  state changes.
- Don't say "trusted by", and don't mention customers, partners or SOC 2.
  None of these exist yet.
- Say up front that the desktop builds aren't code-signed yet.
- Link to a free tool people can try without signing up, not to the
  pricing page.

`/certificate/`, paste an issuer, read the result, then open the
desktop app and show one GO/HOLD/NO-GO receipt. Free options: the
built-in recorder (macOS Cmd+Shift+5, Windows Win+Alt+R), or OBS.
Upload it to YouTube as Unlisted or Public.
