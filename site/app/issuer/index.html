Issuer analysis

Check which controls an issuer keeps over the tokens it issues.

Examples: · ·

Paste an issuer address. You will see whether it can freeze holders, claw back balances or require approval, and what it charges on transfers.

Details

How this is worked out

  • Source: account_info with signer lists at the latest validated ledger, via /api/issuer-state.
  • Each control is read from the account's flags; nothing is inferred.
  • One passing check does not make a token safe. These are the issuer's powers, not a verdict on the issuer.

Wrong result, confusing wording, missing feature or a data discrepancy? Tell us. It goes privately to the founder; nothing is published.

The page and the last input you analyzed are attached so we can reproduce it. Never send keys or seed phrases.
