NOSHASHI Continuity — browser demonstration

To start, open a terminal in the extracted noshashi-continuity-browser folder.
Run: python3 -m http.server 1430 --bind 127.0.0.1
Then open http://127.0.0.1:1430/ in a modern browser. Windows: use py -3 if python3 is unavailable.

Use Recorded payment to review archived XRPL evidence and verify the exported receipt.
Use RLUSD intelligence to inspect a historical issuer snapshot. Wallet handoff uses a simulated provider.
The rehearsal works without an internet connection. The optional general workspace can read public XRPL nodes.
Read-only. No signing, custody or transaction submission. This ZIP contains a browser build.
