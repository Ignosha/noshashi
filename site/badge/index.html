Free · for issuers and listing sites

Show holders what the issuer can still do.

A live badge for a token page, a README or an exchange listing. It reads the issuer's account from validated XRP Ledger state every five minutes. It shows whether one key signs for it, whether it kept the power to freeze, and what fee it charges, with the ledger it was read at. Each badge links to the full certificate.

WHAT IT SHOWS

Ledger facts, each on its own: who can sign, freeze, global freeze, permissioned holding and transfer fee. There is no score and no overall verdict. Supply concentration is left off, because measuring it means walking every holder line, which is too slow for an image. The certificate it links to measures it.

WHEN IT CANNOT READ

If the ledger cannot be read, the badge turns grey and says "unreadable". It never shows green for an issuer it did not read. The colour is the most serious finding shown: red when one key signs alone or a global freeze is on, amber for a retained power or a fee.

Want to know the moment any of this changes? Issuer alerts post to Discord or Telegram.
