Ledger Evidence Report · verification

Confirm a report is authentic

Every Ledger Evidence Report states a SHA-256 over the raw evidence it was built from. Enter it here to see whether NOSHASHI issued a report with that digest, to whom and when. To check the report was not altered, compute the SHA-256 of the evidence file sent with it (for example shasum -a 256 file.json) and compare.
