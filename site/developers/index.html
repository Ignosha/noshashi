Asset Risk API

One issued asset in one call: what its issuer can do to holders, what its XRP order book can actually absorb, what a sale or purchase of a given size would fill at, what was not checked, and a SHA-256 receipt over the report. Read from validated ledgers. Not a rating.

curl "https://www.noshashi.app/api/v1/asset-risk?issuer=rvYAfWj5gh67oV6fW32ZzP3Aw4Eubs59B&currency=USD&size=1000"

No account needed. Up to 30 uncached requests a minute per caller; answers are cached for a minute. Schema noshashi.asset-risk.v1, documented in the API reference. Need more volume, history or monitoring? institutions@noshashi.app.

Compliance API verbs

One edge function serves every verb: https://xiurbiwuwcfowqnpmwki.supabase.co/functions/v1/noshashi-verify/<verb>, with an nsh_live_ key from the desktop app.

  • (bare path) — POST — adjudicate a settlement. verify scope, one credit.
  • authority/check — POST — re-derive an authority certificate's digest from its own body. Free, unauthenticated, reads nothing.
  • receipts/{digest} — GET — a receipt this account or its organization recorded, as it was served. read or verify scope, free.
  • analyze/issuer — POST { issuer } — an issuer's controls, read live from the validated ledger. read or verify scope, free.
  • analyze/address — POST { address } — balance, reserve, owner count and credentials, read live. read or verify scope, free.
  • analyze/transaction — POST { hash } — a transaction's type, parties, result and delivered amount, read live. read or verify scope, free.
  • payment/verify — POST { hash, network?, invoice?, dual_source?, record? } — did this transaction pay this invoice? VERIFIED, HOLD or REJECTED with a reason code and evidence digest; a VERIFIED settlement is recorded once per transaction. verify scope, one credit.
  • payment/signing-key — GET — the Ed25519 public key that signs payment evidence, when signing is configured. Free, unauthenticated.

Request and response shapes, authentication, scopes and rate limits: API reference. Signed event delivery: Webhooks. Everything else: documentation.
