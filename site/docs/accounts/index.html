Two-factor authentication

An authenticator TOTP factor and a completed second-factor challenge are different states. An email one-time sign-in code is not proof of two independent factors. Protected actions remain subject to the existing server authorization and approval rules; this documentation changes none of them.

Availability and privacy

No account feature is declared discontinued by this review. Unverified runtime setup stays UNKNOWN. Do not submit keys or shared credentials. Account, organization and entitlement data use hosted services; public-node queries go to third-party ledger sources. See Trust and Legal.
