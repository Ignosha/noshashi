Evidence

What NOSHASHI keeps with every answer, and how uncertainty is shown rather than hidden.

What is recorded

Each verdict keeps its check list, so it can be walked backwards from the verdict to the facts. Investigations are hash-chained: each event includes the hash of the one before it.

How the decision is made

The verdict is a fixed function of which rules passed. The AI assistant can explain a verdict but has no path to change one.

When a reading is missing

A rule could not be evaluated because the evidence it needs could not be read. This is not a pass, a failure or a soft refusal — it is the absence of an answer, and it says nothing about the subject.

Every reading names the ledger index it came from. A transaction that is not yet validated is labelled as not final.
