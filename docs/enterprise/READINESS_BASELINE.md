## Prioritized implementation

1. Validate privileged policy sessions including enrolled MFA, bound request processing, and suppress sensitive error output. Add behavioral negative tests.
2. Strengthen billing persistence failure handling and replay safety with sandbox/isolated SQL tests. Keep live billing untouched.
3. Prove existing tenant, four-eyes, evidence and concurrency controls in disposable PostgreSQL; record deployment-only dependencies honestly.
4. Add reviewable release/security assurance gates and accurate desktop validation requirements. Do not publish an installer or change signing keys.
5. Complete the evidence-linked enterprise documentation and measured local baselines. SSO, real fleet load, physical-device testing and independent assessment remain separately gated.

Production decision at baseline: **NO-GO for unrestricted enterprise production**. Pilot decision is separately evaluated in [RELEASE_GATE.md](RELEASE_GATE.md); no customer acceptance is implied.
