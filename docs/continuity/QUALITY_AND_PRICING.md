# Continuity decision package and proposed pricing

The higher value deliverable is a review a responsible operations lead can inspect, replay and act on. The software now adds a printable decision report, explicit coverage counts, missing owners and next actions, and reopening of saved rehearsals with integrity and calculation checks.

## Implemented quality improvements

| Capability | Buyer benefit |
| --- | --- |
| Standalone HTML decision report with print styling | Share a readable review with an operations lead and print it to PDF using a browser |
| Companion evidence JSON saved with the report | Retain the inputs, findings, notes, assumptions and matching digest |
| Saved rehearsal reopening | Continue the same review with the saved activity list, proposed rules and reviewer notes |
| Digest verification followed by calculation replay | Identify a changed file or findings inconsistent with its saved inputs |
| Coverage and follow-up counts | See the declared prerequisites covered, missing evidence, baseline gaps and unassigned work |
| Imported source label | Distinguish a file provided by someone else from a new Mainnet read in the workspace |

A report digest and matching replay establish file integrity and calculation consistency. Independent source verification still requires a fresh ledger read. Rehearsal findings apply to the operator-declared domain-access scope. Financial amounts, bridge execution, loan creditworthiness and settlement need additional evidence.

## Proposed enhanced offers

| Offer | Price to test | Defined delivery |
| --- | --- | --- |
| Operational Change Assessment | $3,500 once | One domain, up to 20 accounts and 50 declared activities, a current-rule baseline, two proposed rule-removal options reviewed separately, printable reports, replayable evidence and one review meeting |
| Continuity Pilot | $10,000 over four weeks | One domain, up to 20 accounts, three review cycles, two training sessions, evidence verification and an outcome report against agreed success criteria |
| Institutional subscription | Published $4,000 monthly or $40,000 annually | Agreed recurring team scope, subject to completion and verification of the production capabilities required by the contract |

These are proposed service prices to validate with buyers. The enhanced pilot expands the earlier $5,000 proposal. The enhanced assessment expands the earlier $1,500 Change Review proposal. Published subscription prices are a separate reference for the recurring product.

The price should cover discovery, data preparation, dependency validation with the customer's subject-matter owner, source checking, scenario preparation, review time and delivery. Record actual hours and expenses during the first engagement. A customer with a small portfolio may have a lower cost internal alternative, so document the time and work saved before discussing an annual purchase.

## Evidence needed to support the price

Use the same accounts and cases as the customer's current review. Measure analyst time, missing inputs, incorrect alerts, the time a reviewer needs to understand a finding and whether another review cycle is requested. A 30% review-time reduction remains a proposed pilot target. The team should agree the baseline and acceptance criteria before delivery.

## Before a larger institutional commitment

Validate a real portfolio and the institution's declared dependencies. Verify the native desktop release on the target hardware. Complete the durable team workflow, authentication, organizational permissions, private-record handling, operational support and integrations agreed in the scope. An independent security review and source verification strengthen the deployment case. These items need their own evidence and delivery plan.

## Verification

The related tests cover report escaping, altered digests, modified findings with newly calculated digests, invalid credentials, duplicate accounts, inconsistent ledger timestamps and reopening an existing version 1 rehearsal. The source schema preserves observation metadata. The interface labels reopened files as imported observations. Visual report rendering, independent source validation and native Mac release testing remain to be completed.
