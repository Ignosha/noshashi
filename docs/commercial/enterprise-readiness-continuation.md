## Outstanding gates

- **Ledger and risk:** exercise live positive global-freeze, AccountRoot RequireAuth, and holder-side deep-freeze examples. Bounded mainnet discovery at ledger 108,533,899 did not establish a positive AccountRoot fixture. Circle’s published USDC issuer returned both flags clear from both providers at that ledger. Validate additional asset types, provider history and coverage, and the freshness and licensing of any counterparty intelligence. Public ledger flags alone establish neither sanctions status nor counterparty suitability.
- **Identity, evidence and approval:** bind tenant, authenticated actors, immutable case and approval IDs, ledger evidence, policy version, and validity window. Require distinct eligible approvers, protect auditable state transitions against retries and concurrency, and verify signing, key rotation and append-only audit persistence. Exercise the actual hosted onboarding, session recovery, role revocation, cross-tenant denial, entitlement enforcement and four-eyes flow with dedicated test accounts.
- **API resilience and security:** qualify scoped authentication, shared quotas, provider outage recovery, cancellation, backup restore, monitoring and representative load before hosted pilot commitments. Existing gateway authentication and throttling are local. Independent security review and a hosted Supabase integration run remain open.
- **Desktop:** validate signed and notarized installers on Apple Silicon and Intel where supported, including install, launch, update and recovery on the supported macOS versions. Capture the native CI logs for the same revision, then use the [macOS signing checks](../RELEASE_SIGNING.md) and record the installer checksum, Gatekeeper result, architecture, OS version, app launch, and updater outcome on each test Mac.
- **Commercial and onboarding:** use the [existing packaging proposal](premium-institutional-packaging-proposal.md) as the starting point. Verify every sold entitlement against the tenant and API guards. Agree on pilot cohort, success criteria, capacity, term, support, retention and exit procedure before offering a contract.
