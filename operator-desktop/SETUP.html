NOSHASHI / PRIVATE OPERATOR

Connect revenue securely.

The desktop app reads the hosted operator. Your Stripe reporting key belongs in Cloudflare’s encrypted secrets. The app stores only its operator login in your Mac’s Keychain.

  1. Open Stripe’s API keys page for ignosha. Create a restricted live key named “NOSHASHI operator — reporting”. Grant Read access to subscriptions, charges and account retrieval/account details. All write permissions and unrelated resources should stay None. Dashboard labels can differ; the API permissions are subscription_read, charge_read and limited_account_retrieve.
  2. Open Cloudflare’s NOSHASHI operator settings. Under Variables and Secrets, add a Secret named STRIPE_READ_ONLY_KEY. Paste the restricted key beginning rk_live_ directly into Cloudflare and save/deploy it.
  3. Return to NOSHASHI Operator and choose Refresh Stripe reading. Check the reading date and status. The selected live account must be ignosha. A failed read stays unavailable; a reading older than 24 hours is stale and supplies no current total.

Keep the Stripe key out of chat, source code and the desktop app. The app’s connection field expects the separate operator admin token from your private access file.

What the reading means

The total covers the entire ignosha Stripe account. It is an active fixed-price subscription run rate, with annual prices divided by twelve. It is not product-attributed NOSHASHI sales, cash collected, recognized accounting revenue or profit. Complex prices, discounts and incomplete data require review.

Stripe’s connected ChatGPT tools cannot create or export this runtime key. These authenticated dashboard steps complete the credential setup. The operator’s reporting adapter makes GET requests only; it has no payment, refund or subscription-changing action.
