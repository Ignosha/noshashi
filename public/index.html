ℹ️ ABOUT IGNOSHASHI

      

        
🚀 WHAT IS IGNOSHASHI?

        

          

            IGNOSHASHI is a desktop-grade meme coin trading terminal built for degens who want real tools, real data, and a retro Star Wars pixel-art interface. It runs as both a local web app and an Electron desktop app, giving you a unified terminal for discovering, creating, trading, and tracking meme coins across Ethereum and Solana mainnets.
          

        

      

      

        

          
⚔️ CORE FEATURES

          

            
🛒 Trade — Buy/sell tokens with live price feeds, limit orders, and sniper bots.

            
🪙 Create — Launch your own memecoin with one click. Includes on-chain deployment support.

            
🎰 pump.fun — Browse trending pump.fun coins, view bonding curves, and trade directly.

            
📈 Terminal — Real-time trade feed, candlestick charts, RSI/MACD/Bollinger overlays, and drawing tools.

            
💼 Portfolio — Track holdings, PnL, and asset allocation across connected wallets.

            
👁 Watchlist — Save favorite tokens and get price alerts.

            
🐋 Whale Alerts — Track large wallet movements in real time.

            
📋 Copy Trade — Follow top traders and mirror their moves automatically.

            
🔔 Alerts — Price thresholds, graduation alerts, and safety warnings.

            
🏆 Leaderboard — Compete for top trader status and earn achievements.

          

        

        

          
🔐 BUILT-IN WALLETS

          

            
🔐 Built-in ETH/SOL Wallets — Generate real keypairs stored locally on your machine. Full send/receive support with live on-chain balances.

            
🔒 Secure Storage — Private keys never leave your device. Encrypted backup phrases for recovery.

            
🔄 Network Toggle — Switch between Ethereum and Solana mainnets instantly. All tools adapt to the selected chain.

            
💱 Send/Receive — Transfer ETH or SOL directly from the app with real on-chain transactions.

          

        

      

      

        

          
🛠️ TOOLS & PROTOCOLS

          

            
💰 Staking — Stake tokens and earn yield directly in-app.

            
✈️ Airdrop — Create and manage airdrop campaigns.

            
📅 DCA — Set up dollar-cost averaging orders.

            
⏰ Time-lock — Lock tokens for a set duration.

            
🔐 Token Gating — Gate access to content or features by token holdings.

            
🌉 Bridge — Bridge assets across supported networks.

            
🔒 Rug Safety Net — Real-time safety monitoring with risk scores.

            
🎯 Sniper Bot Pro — Auto-buy new launches matching your filters.

            
📊 Portfolio Pro — Advanced analytics including best/worst performers and ROI tracking.

          

        

        

          
🏗️ TECH STACK

          

            
🖥️ Desktop App — Electron wrapper with native window management, tray icon, and Chrome extension bridge support.

            
⚙️ Backend — Express.js server with WebSocket live feed, SQLite persistence, rate limiting, and Helmet security hardening.

            
⛓ Chains — Ethereum mainnet via public RPC (ethers.js v6) and Solana mainnet via public RPC (@solana/web3.js).

            
🗄️ Database — better-sqlite3 for local storage of wallets, trades, portfolio data, API keys, and settings.

            
🎨 Frontend — Vanilla JS modules with a custom pixel-art CSS theme, VT323/Google Fonts, canvas charts, and CRT effects.

            
🔌 Dev API — REST API with API key auth for bots. Endpoints for state, OHLC, indicators, and trade execution.

            
📡 WebSocket — Real-time trade, create, and graduation events broadcast to all connected clients.

            
🖼️ Design — Star Wars-inspired retro terminal UI with particle starfield, neon glows, scanlines, and pixel fonts.

          

        

      

      

        
🎯 PROJECT GOALS

        

          

            IGNOSHASHI is built around three goals: speed (real-time data and instant trading), control (real wallets, real keys, no custody), and fun (a themed interface that makes memecoin trading feel like commanding a starship). The project is actively developed with new tools, networks, and integrations added regularly. All platform fees (2%) go to the developer fee vault and help fund RPC nodes, server costs, and ongoing development.
